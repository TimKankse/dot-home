# v0.1.22 Release Notes

- Release date November 27, 2026
- Previous release `v0.1.21`

## Dashboard navigation and editing

- Swipe or scroll between dashboard pages with native scroll snapping. Page indicators follow the viewport, and keyboard shortcuts and page indicators jump directly to the selected page.
- Restore the configured default page on mobile, even when the dashboard layout takes time to become ready.
- Show hold feedback when dragging widgets and shortcuts on touch screens. Improve folder pagination so every shortcut stays reachable.
- Pause widget work on hidden tabs and outside the configurable page buffer.

## Integrations and live widgets

- Support current Jellyfin authorization for Now Playing, library stats, and artwork, with HTTP polling when live WebSocket updates are unavailable.
- Share live update connections and polling work across Jellyfin, qBittorrent, SABnzbd, and Netdata widgets.
- Show whether an integration credential is saved or needs replacement. Blank edits preserve existing credentials, and the editor rejects encrypted values copied from Dot Home storage.
- Recover shared integrations from matching legacy widget credentials during upgrade.

## Account and deployment security

- Add profile editing, password changes, and administrator-issued password resets. Revoke stale sessions after sensitive account changes.
- Enforce integration permissions on the server and constrain outbound service requests. Keep reusable integration credentials in server-side storage.
- Update the production runtime to Node.js 24 and update dependencies for current security fixes.

## Upgrading

Back up the SQLite database and preserve your existing `CONFIG_ENCRYPTION_SECRET` before replacing a container. Older Docker installs may store a generated encryption secret in the old container's `/app/.env.local` file. Carry that value forward so stored integration keys remain readable.

Rotate any authentication secret inherited from a revision that tracked `.nextauth_secret` in Git. Rotation signs users out. See the [runtime security and rotation guide](../security-hardening.md#runtime-files-and-authentication-secret-rotation).
