# v0.1.21 Release Notes

- Release date: April 14, 2026
- Previous tagged release in Git history: `v0.1.2` from April 13, 2026
- Compare range: `v0.1.2..v0.1.21`

`v0.1.21` is a focused follow-up to `v0.1.2`, centered on UI polish for settings and configuration flows, plus a stability fix for Jellyfin live updates. In this repository's actual Git ancestry, `v0.1.2` is the direct tagged predecessor of `v0.1.21`.

## Highlights

### Settings and configuration polish

- Reworked the settings modal for better responsive behavior, including a mobile-friendly title row, close action, and compact footer.
- Aligned inputs, selects, searchable selects, and integration pickers with the shared primitive styles used across the app.
- Replaced the custom sync configuration toggle with the shared switch primitive for more consistent interaction and visual behavior.
- Improved spacing, wrapping, and control sizing across boards, appearance, integrations, shortcuts, and user-management screens.

### Dashboard layout improvements

- Added normalized grid column-width handling so dashboard content can stay centered and scale more predictably across breakpoints.
- Updated `DashboardGrid` resize behavior to react more reliably to rendered content width changes.
- Added test coverage around grid dimension and column-width helpers.

### Jellyfin now playing fixes

- Preserved the visible order of active Jellyfin sessions during refreshes and WebSocket updates so live updates no longer reshuffle the list unexpectedly.
- Improved episode labeling in the now-playing view with season and episode formatting when metadata is available.
- Guarded the active session indicator against out-of-range states when the session list changes.
- Added unit tests covering session merge behavior and episode title formatting.
